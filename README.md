# RS-Browser

Installers for RS-Browser, a fast, private, ad-free browser for Windows with built-in ad blocking, passwords, encrypted sync and torrents.

Download the latest `RS-Browser-Setup-<version>.exe` from [Releases](https://github.com/Rafael-Suarez/rs-browser-releases/releases/latest). It installs for your Windows account only (no admin) and then updates itself from here.

The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC" the first time: choose **More info → Run anyway**.
